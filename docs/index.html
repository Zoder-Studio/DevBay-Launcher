Getting started

01

Install the APK

Grab the latest signed release from the GitHub Releases page and install it like any other APK. You may need to allow installs from unknown sources for your browser or file manager.

02

Set as your default launcher

Press the Home button, choose DevBay Launcher from the chooser, and tap Always. You can switch back anytime with the LAUNCHER button at the top of the home screen.

03

Install Shizuku (optional, recommended)

Quick toggle chips (Kill Activities, Slow Animations, Big Fonts, Wireless ADB) and the built-in logcat/crash viewer run through Shizuku. Install it, then open Settings → Pair Shizuku inside DevBay Launcher for step-by-step pairing instructions.

04

Unlock the hidden vault

Long-press any app → Hide app to set up a vault password the first time. After that, type the password directly into the search bar anytime to jump straight into your hidden apps.

05

Set up gestures

Open Settings → Gestures to map swipe-left, swipe-right, and double-tap on the top bar to search, settings, clipboard, notification panel, quick settings, or any installed app.

06

Monitor a GitHub repo

Open Settings → GitHub Monitor, optionally add a personal access token for a higher rate limit, then add any owner/repo to get notified about new issues and PRs.

Showcase

Everything a dev launcher should have

App drawer, sectioned

DEBUG, PINNED, TOOLS, and OTHER — automatically sorted, with fuzzy search across everything.

Shizuku quick toggles

Kill background activities, slow animations, big fonts, and wireless ADB — one tap, no menus.

Hidden app vault

Password, fingerprint, or face unlock. Type your password into the search bar to open it instantly.

App folders

Group apps into folders right on the home screen, QuickStep-style.

Icon pack support

Standard appfilter.xml format — works with Delta Icons, Whicons, Kaaip, and more.

Custom gestures

Swipe left, swipe right, or double-tap the top bar — mapped to any action or any app.

Home-screen widgets

Full AppWidgetHost support — add, resize, and remove real Android widgets.

Notification badges

Real-time unread counts on every app icon, with an opt-in permission prompt.

Clipboard history

Encrypted local history of everything you copy — tap to copy again, long-press to delete.

Logcat & crash viewer

Built-in Shizuku-based viewer, or hand it off to LogFox if it's installed.

GitHub repo monitor

Background sync with notifications for new issues and PRs on any repo you watch.

Custom lock screen

An overlay with clock, battery, and RAM — your real PIN/pattern/fingerprint still handles unlock.
